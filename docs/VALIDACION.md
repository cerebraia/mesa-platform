# Validación de la entrega inicial

- Pruebas automatizadas de precios, variantes y opciones: cinco casos.
- Comprobación TypeScript estricta.
- Compilación Next.js de producción.

Las pruebas cubren importes en centavos, selección obligatoria, opciones inválidas o duplicadas, límites de cantidad y claves de carrito para configuraciones diferentes.

No se realizó revisión visual en navegador. No se probó una base de datos, autenticación ni un despliegue remoto porque no están conectados en esta fase.
